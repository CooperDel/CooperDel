Overview

NOVA was intended to allow control algorithms to be experimentally modeled on lunar rovers on the in-lab analog lunar test bed. The intent of NOVA is to have multiple rovers communicating and operating simultaneously in the test bed, therefore, providing applications to NASA's CADRE project. Additionally, the PhD students in the lab will implement robust autonomy algorithms for obstacle avoidance, for example.
